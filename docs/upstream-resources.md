# Инвентаризация ресурсов оригинального клиента 3.56

Проверена именно клиентская часть. Официальный манифест обновления содержит три
поля: URL Lua-файла, `latest` и `itemsUpdate`. Клиент сравнивает локальную
строку версии с `latest`, открывает уже встроенное окно обновления и скачивает
Lua по `updateurl`.

## Что имеет смысл отделять

| Ресурс | Назначение | Действие в форке |
| --- | --- | --- |
| `ArzMarketV3/updateArzMarket.js` | Официальное уведомление о новой версии | Читает только watcher. Клиенты форка его не запрашивают. |
| Собственный `release/updateArzMarket.js` | Версия, которую разрешил владелец форка | Читают клиенты. Публикуется вручную. |
| Собственный `release/ArzMarket.lua` | Проверенный клиентский Lua-релиз | Скачивается только по нажатию «Обновить сейчас». |
| `ArzMarketV3/items.json`, `items_data*.json` | Каталог/данные предметов | Не дублировать автоматически: при необходимости отдельно согласовать источник и версию. |
| `avg_price/*.json` | Справочные цены | Оставить штатным ресурсом, пока автор не дал отдельную схему зеркала. |
| `scripts_list.json`, `sputnik.json`, `youtube_list.json`, `buy.json` | Дополнительные разделы интерфейса | Не являются частью механизма обновления и не должны копироваться «вслепую». |

Marketplace API и его авторизация не входят в этот форк: этот набор не меняет
параметры запросов, токены, UID или серверные ограничения.
